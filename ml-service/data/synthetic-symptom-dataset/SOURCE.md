# Dataset: synthetic-symptom-dataset

**This is synthetic data, not a real veterinary dataset.**

## Why synthetic

The M1 spec ([docs/specs/M1-baseline-symptom-model.md](../../../docs/specs/M1-baseline-symptom-model.md))
called for a "public cattle disease dataset." A genuinely public, auth-free, ML-ready one
wasn't reliably fetchable in this environment (the well-known ones are Kaggle-hosted and
need an account/API key). Rather than block the whole M1→M2→M3 pipeline on dataset
sourcing, this generates a clearly-labeled synthetic dataset with a realistic
symptom/disease schema, so training → inference → tests are all real and working end to
end. Swapping in genuine data later requires only replacing the CSV this script produces —
`app/models/symptom_model.py` and the training script don't change.

## How it's generated

`ml-service/training/generate_synthetic_data.py` — for each of 5 classes (4 diseases +
"Healthy"), each of the 11 symptoms in `FEATURES` (`app/models/symptom_model.py`) is drawn
from a per-class Bernoulli probability (a hand-authored profile approximating which
symptoms are typical of each disease), with an 8% chance any given value is left missing
(simulating incomplete real-world intake). 150 rows per class, 750 total. Seeded (`seed=42`
by default) for reproducibility.
