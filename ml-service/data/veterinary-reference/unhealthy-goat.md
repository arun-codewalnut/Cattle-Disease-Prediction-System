# Unhealthy (Goat)

The goat image model is a binary screen — it can tell that a photo doesn't look like a
healthy goat, but it has no disease-specific classes to say *what's* wrong. This is a real,
disclosed limitation: no goat-disease image dataset was found (see
`data/goat-images/SOURCE.md`), so "Unhealthy" here means "something about this animal's
appearance differs from healthy reference photos," not a diagnosis of any particular
condition. Farm-relevant conditions this could reflect include (but are not identified by
this model) poor body condition, visible skin lesions, lameness, or general lethargy/
illness posture.

This is a general educational summary for a learning project, not veterinary guidance —
see the project's disclaimer.

## Precautions

- Isolate the animal from the rest of the herd until a vet has assessed it, since a visibly unwell goat could have a contagious condition.
- Check for common visible signs a photo alone won't capture — appetite, temperature, breathing, and mobility — since those narrow down what to tell a vet.
- Don't assume a specific disease from this result alone — it flags that something looks off, not what it is.

## Next steps

- Consult a veterinarian for an in-person exam and, if needed, lab testing — this is the only way to get an actual diagnosis from here.
- Take a closer, well-lit photo of any specific area of concern (skin, eyes, mouth, hooves) if a follow-up visit isn't immediately possible, to help describe the issue.
- Monitor the rest of the herd for similar signs, in case the cause is contagious.
